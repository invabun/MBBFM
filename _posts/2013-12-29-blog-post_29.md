<span style="font-family: Arial; font-size: 13px;">每个人成功都有不一样的经历</span><br />
<span style="font-family: Arial; font-size: 13px;">更重要的是有不一样的起点</span><br />
<span style="font-family: Arial; font-size: 13px;">但是这些并不会影响成功者达成目标</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">如果发现自己没有达到目标</span><br />
<span style="font-family: Arial; font-size: 13px;">而自己起点没有别人好 又或 不比别人差</span><br />
<span style="font-family: Arial; font-size: 13px;">有认真的面对自己</span><br />
<span style="font-family: Arial; font-size: 13px;">刨去所有自我安慰的借口</span><br />
<span style="font-family: Arial; font-size: 13px;">看清楚自己的核心思想去了解自己到底想要什么吗?</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">人不面对自己，很容易失去目标</span><br />
<span style="font-family: Arial; font-size: 13px;">失去目标做事情就很容易放弃</span><br />
<span style="font-family: Arial; font-size: 13px;">放弃多了就很容易失去信心</span><br />
<span style="font-family: Arial; font-size: 13px;">失去信心 一切就免谈了。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<a name='more'></a><br /><br />
<span style="font-family: Arial; font-size: 13px;">写到这里</span><br />
<span style="font-family: Arial; font-size: 13px;">好像送殡一般的 送完就没了</span><br />
<span style="font-family: Arial; font-size: 13px;">但是这并不是一个终结。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">每一个生命都有自己的意义</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">话已经说在前方</span><br />
<span style="font-family: Arial; font-size: 13px;">“人不面对自己” 这就是一切恶根源的起点。</span><br />
<span style="font-family: Arial; font-size: 13px;">有如吸引力法则 它会开始不断的吸引更糟糕的结果直到结束</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">没有达到目标那么就从起点开始改变吧。</span><br />
<span style="font-family: Arial; font-size: 13px;">“面对自己”&nbsp;</span><br />
<span style="font-family: Arial; font-size: 13px;">这个动作也许对某些人来说是非常困难的。</span><br />
<span style="font-family: Arial; font-size: 13px;">不是每个人都愿意面对自己。</span><br />
<span style="font-family: Arial; font-size: 13px;">我们可以在任何时候面对自己。</span><br />
<span style="font-family: Arial; font-size: 13px;">所有的失败都是从逃避自己开始。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">每个人都说 要有钱 要有很多很多钱</span><br />
<span style="font-family: Arial; font-size: 13px;">要享受 要快乐 要幸福</span><br />
<span style="font-family: Arial; font-size: 13px;">这些都不是目标</span><br />
<span style="font-family: Arial; font-size: 13px;">如果这些目标中没有自己在里面。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">只有面对自己 才能发现问题在那里</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">这个世界上 没有比自己更加了解自己的人</span><br />
<span style="font-family: Arial; font-size: 13px;">自己的内心只有自己能够进入</span><br />
<span style="font-family: Arial; font-size: 13px;">问题在于自己想改变的意愿有多大。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">当然有人的起点很低</span><br />
<span style="font-family: Arial; font-size: 13px;">这个起点 在于知道 和 不知道的差别</span><br />
<span style="font-family: Arial; font-size: 13px;">一个人不知道需要面对自己</span><br />
<span style="font-family: Arial; font-size: 13px;">那么他就只会选择继续逃避</span><br />
<span style="font-family: Arial; font-size: 13px;">结局也就只有这样了 或者找到一些机遇了</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">希望这样的朋友能看到我的文章&nbsp;</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">我也是一个不敢面对自己的人</span><br />
<span style="font-family: Arial; font-size: 13px;">但是我不是没有欲望 不是没有野心</span><br />
<span style="font-family: Arial; font-size: 13px;">我有野心要在台上对大家说话</span><br />
<span style="font-family: Arial; font-size: 13px;">有野心希望学习更多可以做一个讲师</span><br />
<span style="font-family: Arial; font-size: 13px;">希望可以帮助很多人了解自己</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">可是我最不了解的还是自己</span><br />
<span style="font-family: Arial; font-size: 13px;">这个不了解 也不是真的不了解</span><br />
<span style="font-family: Arial; font-size: 13px;">而是我自己不敢面对</span><br />
<span style="font-family: Arial; font-size: 13px;">我最强的一个能力叫做 钻牛角尖</span><br />
<span style="font-family: Arial; font-size: 13px;">也就因为不想让它在脑中钻</span><br />
<span style="font-family: Arial; font-size: 13px;">所以写下来了</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">我并不是一个很成功的人</span><br />
<span style="font-family: Arial; font-size: 13px;">失败也失败很多次了</span><br />
<span style="font-family: Arial; font-size: 13px;">为什么失败？既然已经失败了 说出来的都会变成借口</span><br />
<span style="font-family: Arial; font-size: 13px;">自己记得教训下次绕过去就好。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">很多情况 失败也是因为自己不面对自己。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">我有目标 是一个10年拥有3千万的净资产。</span><br />
<span style="font-family: Arial; font-size: 13px;">可是定了这个目标几个月下来</span><br />
<span style="font-family: Arial; font-size: 13px;">我距离目标又远了 从无产变成负资产</span><br />
<span style="font-family: Arial; font-size: 13px;">比起很多成功人士的经历 当然什么都不是咯</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">而认真面对自己</span><br />
<span style="font-family: Arial; font-size: 13px;">才发现自己正在逃避这个目标</span><br />
<span style="font-family: Arial; font-size: 13px;">不停让自己疏远它</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">一是因为无知</span><br />
<span style="font-family: Arial; font-size: 13px;">因为自己知道自己没有任何办法去达成</span><br />
<span style="font-family: Arial; font-size: 13px;">没有人脉没有基础 连专业都没有 能干嘛？&nbsp;</span><br />
<span style="font-family: Arial; font-size: 13px;">呐呐呐呐呐！</span><br />
<span style="font-family: Arial; font-size: 13px;">这就是负面思考 恶意教材</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">没有人脉可以累计</span><br />
<span style="font-family: Arial; font-size: 13px;">没有能力可以磨练</span><br />
<span style="font-family: Arial; font-size: 13px;">有脑袋，有时间&nbsp;</span><br />
<span style="font-family: Arial; font-size: 13px;">难道就不能增强吗?</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">面对自己吧？</span><br />
<span style="font-family: Arial; font-size: 13px;">到底为了什么？</span><br />
<span style="font-family: Arial; font-size: 13px;">目标到底是什么？</span><br />
<span style="font-family: Arial; font-size: 13px;">人生这场戏到底要怎么演？</span><br />
<span style="font-family: Arial; font-size: 13px;">我们才是自己的导演。</span><br />
<span style="font-family: Arial; font-size: 13px;"></span><br />
<span style="font-family: Arial; font-size: 13px;">今天我写到这里了</span><br />
<span style="font-family: Arial; font-size: 13px;">我正准备继续写属于我自己的剧本。</span>
