<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　每个人都是有不一样的性格，就像这个世界上没有两片相同的叶子一样，而每个人发展的道路跟自己的性格都是有着极大的关系，在dota2的世界中性格是影响着整个团队的事情，每个玩家的性格会造成比赛不一样的结果，所以dota2中性格是至关重要的，没有一个好的性格，想要胜利是多么的艰难啊！</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);"></span></div>

<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　<strong style="-webkit-touch-callout: none;">1.悲观</strong></span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　如今的社会压力给很多人是施以极大的压力，小时候那种无忧无虑已经变成了事事忧虑，所以悲观的性格早已深入我们的内心，这样也就养成了不少人悲观的性格，那么悲观的人在dota2中也是非常常见的。dota2里面有两种沟通的手段，一是语音；二是打字。那么性格悲观的人就是通过这两种沟通的手段来表现的。表现的形式就是通过语音和打字向队友表示自己的感受，一般说的话都是“我们赢不了”、“我们跟对面的差距太大了，已经不行了！”“输了，没法打了”，这样的话语时时刻刻在向队友们倾诉，就是这样的话让队友早早放弃了抵挡，也让自己失去了赢得比赛的信心，dota2是一种团体的比赛，是一种竞技的比赛，是一种肉体和精神互拼的比赛，不是每一场比赛都会顺利，不是每一次胜利都是顺风。悲观的人在这样的比赛中往往给我们呈现的是一种懦夫的形象。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px; text-align: start;">
<a href="openimg://img0.pcgames.com.cn/pcgames/1411/21/4573373_10.jpg" style="-webkit-text-size-adjust: auto; -webkit-touch-callout: none; background-color: rgba(255, 255, 255, 0);"><span style="color: black;"><img src="http://img0.pcgames.com.cn/pcgames/1411/21/4573373_10.jpg" style="-webkit-touch-callout: none; max-width: 100%;" /></span></a></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　悲观虽然对dota2的战斗有着极大的影响，但是适当的改变也是能够扭转战局，在自己的队伍有着一些劣势的时候你要克制住自己对“输”这个字的看法，虽然你心里会想，但是一定不要说出来，一个优秀的dota2玩家坚定乐观是一定要有的，在队伍劣势的时候如果你说了一些关于输的言论，那么会成为压死你们的最后一根稻草。所以积极的话语一定要说的更多一些，而且光说也是不行的，什么事情都是落在实际行动上，比如你是一个gank非常强的玩家，那么你需要做的就是要带动整个团队的节奏，队伍处于劣势的时候对面也一定有处于优势的玩家，而你的任务就是积极组织队友对这种优势很大的玩家进行gank，而且一定要多次，对面的玩家面临多次gank之后心情或多或少会改变一些， 对面也是会不理智的，这个时候你们就是会得到重新取得优势的结果。胜利也是会重新来到你们这边。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　悲观的人一定要学会克制自己对于悲观的看法，dota2中战略也是非常重要的，适当的鼓励会让自己的队友也更加坚信自己，更加的信任团队。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　<strong style="-webkit-touch-callout: none;">2.自私</strong></span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　中华传统美德中无私奉献一直都是我们倡导的，不知道什么时候随着社会的发展，自私倒是成了主流，不得不说这是一种悲哀，dota2中每个玩家都是有着不一样的位置，核心英雄受到了非常多的照顾，劣单受到了对面极大的打击，中单等级经济都是自给自足，游走辅助没等级没装备没钱，而这样的位置也是缺一不可的，这样的格局一旦打破想要胜利是很难的，但是在路人局中往往是自私的，不是每个人都想成为一个游走辅助，而这样的人想的就是“凭什么我就该什么都没有”，其实想想也是挺悲哀的一个事情，我并不是嘲笑这样自私的人，可能是社会带给他极大的压力，让他不得不变得自私，也许他小时候也会无私奉献，只不过经历了风吹雨打，性格也变成了自私，但是每个位置是必须要有人使用的，后期核心需要成长，需要你的帮助，但是自私会害得全队输了比赛，可能有人不在意输赢，只在意自己的快乐，但是你这种快乐是畸形的，是建立在别人痛苦之上的，这样的自私我只能说你错了。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　不是每个人天生就是自私的，我认为对于自私的人交流会是一个更加好的选择，dota2从刚进入游戏选人的时候就是能够互相的交流，我这里说的交流并不是那种指责，想要胜利指责是毫无作用的一种方式，也是最坏的一种方式，在选人的时候交流自己的选人和研究对面的阵容是非常必要的，这样的交流是可以掌握自己的队友的看法，这样才是能够更加了解相互之间的想法， 有了沟通选人就是能够更加的合理，对于不想用辅助的人也不要过分的批评，有些时候退一步真的是能够海阔天空，适当的转变会有更好的选择，现在的dota2阵容是赢得胜利重要的一点，很多时候胜利就是从阵容开始，不要自私，任何一个人的无私都是会让团队胜利的。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　<strong style="-webkit-touch-callout: none;">3.依赖</strong></span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　往往总依赖别人的人总是不容易成长的，就像是温室里的花朵没经历过风雨交加、就像是动物园里的老虎没经历过优胜劣汰。把每一场胜利都是依赖给别人，这是一种不负责的态度，dota2这样的团队比赛每一个人都是要承担起自己的责任，而你这样的依赖却把自己的责任抛给了队友，难道在dota2的游戏中你是抱着玩玩的态度吗？依赖别人是可以的，但是要分场合，这样的团队比赛中把所有的希望都给了别人那么你进行比赛还有什么意义吗？如果这样的话你永远不会成长，你永远无法在dota2的世界中取得好成绩，你永远没法成长，要知道dota2的比赛是残酷的，只有胜利和失败，失败的人永远会被人早早的遗忘。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px; text-align: start;">
<a href="openimg://img0.pcgames.com.cn/pcgames/1411/21/4573373_3.png" style="-webkit-text-size-adjust: auto; -webkit-touch-callout: none; background-color: rgba(255, 255, 255, 0);"><span style="color: black;"><img src="http://img0.pcgames.com.cn/pcgames/1411/21/4573373_3.png" style="-webkit-touch-callout: none; max-width: 100%;" /></span></a></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　我研究过不少依赖队友的人，在现实生活中他们也是习惯于依赖别人，习惯依赖的人在dota2中也是依赖着别人，他们已经太长时间没有独立，没有自己的思想，其实这样的人都是挺让人值得同情的，就像是一个傀儡，对于这样的玩家更加强烈的话语能够更加的激发他们的斗志，任何在玩dota2的玩家斗志都不能够丧失，要是没有那种激情，那种斗志，那么胜利还有什么意义呢？依赖别人也不是那么靠谱的，你可能会比的队友更加强，红花虽然需要绿叶来衬托，但是你想过吗？你的队友也可能是一个绿叶呢？自己强大起来才是能够胜利，胜利永远是五个人齐心协力、永远是五个人披荆斩棘，任何一个人掉队都不行，任何一个人不奋斗都不行！</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　<strong style="-webkit-touch-callout: none;">4.犹豫</strong></span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　一般接触dota2的玩家都是非常的年轻，年轻是优势也是劣势，优势的地方就是在于经济充沛、敢打敢拼。而劣势就是远远没有中年人那种成熟稳重。太年轻往往就会陷入犹豫中，人总是时时刻刻都处于十字路口，怎么样选择，该怎么选择，都是问题，dota2中每一个选择可能都会影响着比赛的最终结果。可能你在场外有着充分的时间可以思考，但是在比赛中仅仅那一瞬间就要你进行选择，选择对了比赛的天平倾向了你们，选择错了，失败在向你招手。每个人都是会犹豫的，有时候选择真的是让你很痛苦，但是没有办法，选择了就要坚持，哪怕是失败了也只能在比赛结束后反省，该打团战的时候你带线、该推塔的时候你打钱、该gank的时候你霸线，虽然你选择了，但是你的一只脚已经迈向了失败。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　人生处处面临选择，dota2也是处处面临选择，就比如在高地的时候已经给对面全部消灭了，过了一会对方全部要复活了，有的人认为坚持拆家，有的人认为该走了，自己的团队状态都不是很好的时候，还是仍旧要坚持打下去，这样我认为真的是没有必要，这个时候如果稳重一些，拿下roshan、刷刷野，补充一下状态不也是很好的吗？就是这么一个选择失误，自己的团队也是被全部消灭，对面同样能够上高地，这样的优势就消散了，选择可能是一个玩家，可能是一个团队都是要做的，所以比赛输了犹豫不决是最大的弱点，一个团队一定要有统一的话语，统一的行动，有分歧可以，等到比赛结束后再说，这个时候哪怕错了也一定要在一起，这样才是能够打出最完美的配合。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　<strong style="-webkit-touch-callout: none;">5.随意</strong></span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　如果你不能认真地对待每一场比赛，那么我认为你可以放弃dota2这个游戏，dota2虽然是一个游戏，但是认真首先是你应该有的态度，哪怕是对手跟你差了很多，但是我知道认真不仅是给予对方的尊重，也是让你成长，随意真的不是一个好的性格，很多人认为随意就是洒脱，但是这绝对是两种对立。随意的玩家，玩着认真地dota2，随意的点技能，随意的出装，坑害的永远是自己和队友的利益，永远让对手私底下偷乐。而队友也是会肆意的辱骂。这样的随意你想要吗？受不到所有人的尊重，那么做人就是失败的。</span></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px; text-align: start;">
<a href="openimg://img0.pcgames.com.cn/pcgames/1411/21/4573373_2.png" style="-webkit-text-size-adjust: auto; -webkit-touch-callout: none; background-color: rgba(255, 255, 255, 0);"><span style="color: black;"><img src="http://img0.pcgames.com.cn/pcgames/1411/21/4573373_2.png" style="-webkit-touch-callout: none; max-width: 100%;" /></span></a></div>
<div style="-webkit-touch-callout: none; margin-bottom: 5pt; margin-top: 0px;">
<span style="-webkit-text-size-adjust: auto; background-color: rgba(255, 255, 255, 0);">　　面对随意的人其实真的不好解决，因为随意的人对胜利的需求也不是很大，他们注重的更多是快乐，更多的是随心所欲，但是如果想要改变，那么想要改变这样需要的就是心境的改变，做什么事情都是会有动机的，那么如果你的队友有这样随意的，那么你要抓住他的动机才是可以转变的，如果他喜欢玩，你可以引导他，以好玩的东西为引导，引导他出装，引导他配合自己消灭敌人，但是一场两场比赛是不能够改变的，只有让他真正懂得dota2的意义才是可以真正的改变。</span></div>
