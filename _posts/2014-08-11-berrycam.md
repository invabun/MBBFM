Steps to get BerryCam to run on your Raspberry Pi and iOS Device.</h2>
<h2 style="background: rgb(255, 255, 255); border: 0px; clear: both; color: #555555; font-family: ClarendonLT, 'Helvetica Neue', Helvetica, Arial, sans-serif; font-weight: normal; margin: 0px 0px 15px; padding: 0px; vertical-align: baseline;">

Make sure that you have the&nbsp;<strong style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;">camera module</strong>&nbsp;for the Raspberry Pi installed. If you need more information on how to do this, visit&nbsp;<a href="http://www.raspberrypi.org/camera/" style="background: transparent; border: 0px; color: #0066ff; margin: 0px; outline: none; padding: 0px; text-decoration: none; vertical-align: baseline;" target="_blank" title="More information on the Raspberry Pi Camera">http://www.raspberrypi.org/camera/</a><br />
Once the camera has been installed, please make sure that you have Python. If you are using Raspbian OS, then this should be installed already.</div>

Installing BerryCam on Raspberry Pi</h2>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
First of all, we will need to find the IP address of the Raspberry Pi on your network. Start&nbsp;<strong style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;">LXTerminal</strong>&nbsp;on the Raspberry Pi using the icon on the desktop. Or if you use an SSH client you can connect to this from another machine using your username and password. Recommended SSH clients for Mac are the standard MacOSX Terminal app, or on Windows something like Putty.&nbsp;<a href="http://www.putty.org/" style="background: transparent; border: 0px; color: #0066ff; margin: 0px; outline: none; padding: 0px; text-decoration: none; vertical-align: baseline;" target="_blank" title="Link to Putty SSH Client">http://www.putty.org/</a></div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
To get this information type:</div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">ifconfig</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
This will return the IP address. Take a note of this and using the settings panel within the app, enter these details into the address field. The port number, as default is set to 8000 although advanced users may decide to change this is necessary.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
The username is usually pi for the device. To connect using SSH:</div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">ssh pi@XX.XX.XX.XX</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
and press (where the XX’s is the IP address) and supply your password at the following prompt.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
It’s always good to make sure a lot of the libraries and packages are up to date. You can do this by using</div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">apt-get update</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
Once updated it’s also a good idea to fetch the new updates with</div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">apt-get upgrade</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
Once logged in use the following commands to download the necessary Python code to run on your Raspberry Pi.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
<em style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;">Download and install the Python script into an easy to locate location. The /home directory is recommended (it’s easier to find)</em></div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">cd /home
sudo wget <a href="https://bitbucket.org/fotosyn/fotosynlabs/raw/9819edca892700e459b828517bba82b0984c82e4/BerryCam/berryCam.py" rel="nofollow" style="background: transparent; border: 0px; color: #0066ff; margin: 0px; outline: none; padding: 0px; text-decoration: none; vertical-align: baseline;">https://bitbucket.org/fotosyn/fotosynlabs/raw/9819edca892700e459b828517bba82b0984c82e4/BerryCam/berryCam.py</a></pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
<em style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;">To check this has been downloaded and unpacked, or set up as a file issue the command:</em></div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">ls</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
This will list files currently in home. You will notice the new Python&nbsp;<strong style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;"><code style="background-attachment: initial; background-clip: initial; background-image: initial; background-origin: initial; background-position: initial; background-repeat: initial; background-size: initial; border: 0px; font-family: 'Courier New', Courier, serif; margin: 0px; overflow: auto; padding: 2px; vertical-align: baseline;">berryCam.py</code></strong>&nbsp;file. This is needed to provide the link between the iOS device and the Raspberry Pi.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
<a href="http://i2.wp.com/www.fotosyn.com/wp-content/uploads/2013/08/Screen-Shot-2013-08-14-at-21.48.28.png" rel="lightbox-0" style="background: transparent; border: 0px; color: #0066ff; margin: 0px; outline: none; padding: 0px; text-decoration: none; vertical-align: baseline;"><img alt="Screen Shot 2013-08-14 at 21.48.28" class="alignleft size-full wp-image-2040" src="http://i2.wp.com/www.fotosyn.com/wp-content/uploads/2013/08/Screen-Shot-2013-08-14-at-21.48.28.png?resize=726%2C478" height="391" style="background: transparent; border: none; display: inline; float: left; height: auto; margin-bottom: 12px; margin-left: 0px; margin-right: 24px !important; margin-top: 4px; max-width: 100%; padding: 0px; vertical-align: baseline;" width="594" /></a></div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">

<h2 style="background: rgb(255, 255, 255); border: 0px; clear: both; color: #555555; font-family: ClarendonLT, 'Helvetica Neue', Helvetica, Arial, sans-serif; font-weight: normal; margin: 0px 0px 15px; padding: 0px; vertical-align: baseline;">
Using BerryCam</h2>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
Once you have entered the IP address,&nbsp;<strong style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;"><code style="background-attachment: initial; background-clip: initial; background-image: initial; background-origin: initial; background-position: initial; background-repeat: initial; background-size: initial; border: 0px; font-family: 'Courier New', Courier, serif; margin: 0px; overflow: auto; padding: 2px; vertical-align: baseline;">berryCam.py</code></strong>&nbsp;needs to be run as a Python process in order to provide the necessary links to allow the BerryCam iOS app to trigger the camera, provide previews and save files.&nbsp;<em style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;">To run simply enter:</em></div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">sudo python /home/berryCam.py &amp;</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
<em style="background: transparent; border: 0px; margin: 0px; padding: 0px; vertical-align: baseline;">The Python script will run in the background and you will see the following message:</em></div>
<pre style="background: rgb(255, 255, 255); border: 1px solid rgb(228, 228, 228); color: #7d7d7b; margin-bottom: 20px; overflow: auto; padding: 10px; vertical-align: baseline;">B E R R Y C A M -- Listening on port 8000
Please ensure your BerryCam App is installed and running on your iOS Device</pre>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
Make sure both devices are connected on the same local network (generally your cellular connection won’t work. Wifi will be easiest). To set up the connection on the iOS App, tap the settings button (gears icon) and input the IP address you obtained earlier in the labelled input field. Close settings to return to the main camera controls.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
Tap the refresh button within the BerryCam app on your iOS device. If your device has been recognised you will see the Connected message and the refresh icon will change to a camera icon. Pressing this will trigger the camera on the Raspberry Pi. In the terminal window you will see some activity as the Raspberry Pi handles the requests.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
After a short pause, the image will then appear in your iOS device.</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">

Viewing and Saving images to your iOS Device</h2>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
By default, images are captured into a folder named berrycam. Images are organised by timestamped folders. You can access these directly on an iOS device by choosing the enlarge button (overlaid right bottom of preview). From here, your image will be opened up in Safari, where you can view full size and tap and hold to save to your camera roll. At any time you can access your save imaages in a web broeser by simply typing:</div>
<div style="background: rgb(255, 255, 255); border: 0px; color: #7d7d7b; font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 0.75em; line-height: 1.7em; margin-bottom: 20px; padding: 0px; vertical-align: baseline;">
http:XX.XX.XX.XX:8000/berrycam/ (where XX.XX.XX.XX is the IP address of your Raspberry Pi)</div>
